# 文章管理后台页面设计

**日期：** 2026-08-14  
**状态：** 已获用户确认，待用户审阅文档后进入实施计划

## 目标

新建 `/admin/articles` 后台页面，以 Pencil 当前选中的“文章管理”画布为视觉基准。页面应包含导航、文章概览指标、搜索与筛选、文章表格和分页，并将重复 UI 拆为可复用组件。

## 已确认范围

- 创建独立的 `/admin/articles` 路由，不替换现有页面。
- 视觉忠实复刻当前选中画布的中文后台管理界面。
- 使用本地示例文章数据；不新增或假设后端文章 API。
- 提供前端交互：关键词搜索、分类筛选、状态筛选、分页及行操作入口。
- “新建文章”使用预留创建路由或明确的前端提示，不伪装为已接入的创建能力。

## 页面结构

`ArticleManagementPage` 负责组合页面与本地状态；其余组件保持单一职责：

- `AdminSidebar`：后台侧边导航与当前“文章管理”高亮。
- `ArticleStatCard`：顶部指标卡，接受标题、数值、说明和强调色。
- `ArticleFilters`：关键词输入、分类和状态下拉筛选，向页面回传受控值。
- `ArticleTable`：文章行、状态标签、行操作及空结果状态。
- `ArticlePagination`：基于已过滤结果的本地分页控制。

页面沿用仓库已有 shadcn/UI 基础组件、图标和 Tailwind 约定，避免新增依赖。桌面端以左侧导航与右侧内容区并排布局；窄屏时导航和表格仍须可访问，表格容器允许横向滚动。

## 数据与交互

页面内维护一组与设计稿相符的文章示例数据，包含标题、分类、作者、状态、发布时间与阅读量。指标卡根据该数据计算或显示对应汇总值。

- 搜索匹配文章标题、作者和分类。
- 分类与状态筛选可组合；结果变化后回到第一页。
- 分页只作用于筛选结果，空结果显示清晰提示。
- 编辑与更多操作仅作为可访问的界面入口；未接入行为时提供明确提示。
- 新建文章入口指向预留路径或显示“即将支持”的提示，避免死链接和虚假成功状态。

## 可访问性与质量

- 所有图标按钮提供可读标签和 tooltip。
- 输入、筛选和分页可用键盘操作，状态标签有足够对比度。
- 表格使用语义化的表格组件与表头。
- 页面标题层级清晰，空状态与结果数量会向辅助技术说明变化。

## 验收与测试

- 访问 `/admin/articles` 可看到与 Pencil 设计一致的后台文章管理页。
- 搜索、分类、状态筛选可正确缩小文章集并重置分页。
- 分页能在已过滤数据中翻页；无结果时不显示空白表格。
- 新建与行操作不会导致无反馈或错误跳转。
- 为状态处理和关键交互补充项目现有测试模式下的覆盖。

## 不在本次范围

- 服务端文章 CRUD、身份/角色权限与数据库迁移。
- 富文本编辑器、新建文章表单与文章详情页。
- 批量操作、导入导出与真实数据分析。

## 自检结论

- 范围限定为单一路由及其可复用展示/交互组件。
- 本地数据与未实现操作边界明确，不会暗示不存在的 API 能力。
- 页面、组件、交互和验收标准相互对应，未遗留待决项。
